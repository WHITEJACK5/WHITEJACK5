## Selected Work

### 01 // TRACER

**Real-Time Mule-Ring Defense for Razorpay**

A defense-only risk engine combining XGBoost scoring, SHAP attribution,
NetworkX graph detection, a bounded decision agent, and an audit ledger.

**Stack:** Python · FastAPI · Next.js · XGBoost · SHAP · NetworkX

[Open repository](https://github.com/WHITEJACK5/TRACER-Real-Time-Mule-Ring-Defense)

---

### 02 // LOAN DEFAULT RISK

**Modeling risk into better decisions**

A loan default-risk system combining calibrated probability-of-default
modeling, profit-aware policy, SHAP explanations, A/B experimentation,
and a FastAPI service.

**Stack:** Python · LightGBM · SHAP · FastAPI · MLflow · Docker

[Open repository](https://github.com/WHITEJACK5/loan-default-risk) · [Demo](https://whitejack5-loan-default-risk.hf.space)

---

### 03 // WHITE COLLARS

**Full-stack job portal**

A job platform for discovering company-site jobs, saving application
documents, applying in one click, and managing employer workflows through
a staged, security-conscious monorepo architecture.

**Stack:** Node.js · Express · MongoDB · EJS · Turborepo · Docker

[Open repository](https://github.com/WHITEJACK5/white-collars)

---

### 04 // ARCHVISION AI

**AI-powered software architecture studio**

Turns natural language, OpenAPI specifications, SQL schemas, and
repositories into editable, validated UML and architecture diagrams.

**Stack:** Next.js · TypeScript · ReactFlow · Mermaid · Prisma
